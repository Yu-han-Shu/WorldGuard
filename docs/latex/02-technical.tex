\section{系统结构}
React / TypeScript 工作台通过本机 HTTP API 调用 Python 业务层。业务层持有测试任务与案例状态，调用规划器和独立几何验收器；LIVE 模式通过 Node.js 适配层接入官方 AGH Host，再由受限 MCP 服务暴露业务工具。浏览器不持有模型 Key。

\textbf{核心链路：}任务确认 → CampaignRunner → 本机认证 MCP → 官方 AGH Host / 模型适配器 → 工具调用 → 当前原始地图验收 → 恢复或停止 → 报告与证据。

\section{可运行环境}
Python 项目声明为 3.11 及以上；现有本机记录为 Windows、Python 3.13、Node 24。前端使用 React、TypeScript 与 Vite，依赖版本以 package-lock.json 为准。后端依赖见 pyproject.toml。默认离线模式无需模型凭据。
\begin{verbatim}
cd worldguard
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[api,mcp]"
.\.venv\Scripts\python.exe -m worldguard.api --port 8520
\end{verbatim}
另开终端进入 \texttt{worldguard/frontend}：
\begin{verbatim}
npm ci
$env:VITE_WORLDGUARD_API_URL = 'http://127.0.0.1:8520'
npm run dev -- --port 5173 --strictPort
\end{verbatim}
打开 \url{http://127.0.0.1:5173/\#agent}，载入示例策略、填写目标、准备并确认计划、执行后查看报告。不要把旧 Streamlit 的 8510 端口作为当前前端入口。

\section{LIVE Agnes 配置}
参照仓库的 AGH 安装说明恢复并构建固定版本官方运行时，在官方界面配置模型。将 \nolinkurl{model_budget.example.json} 复制为本机配置，填写凭据 home、AGH 目录和显式授权记录；Key 由官方凭据存储管理，不写入公开仓库。

本机配置需有单运行请求、输出与时间上限，API 启动前设置 \nolinkurl{WORLDGUARD_LIVE_CONFIG} 指向该文件。配置不完整或预算不足时应拒绝 LIVE，不能静默伪装成模型运行。默认模板禁用真实调用。

记录中的单运行限制为 30 次请求、300 秒总时限、90 秒单请求等待；每次重试与辅助请求都纳入预算。工具白名单排除任意 shell、文件写入和未经授权的外部网络操作。
\section{三类样例复现}
每个样例目录含 before / after 地图、任务约束、故障、路径、审计、结果与 manifest。先验证各 JSON 规范化内容的 SHA-256，再在新目录重放：
\begin{verbatim}
python -m worldguard.cli replay --case-dir CASE_DIR \
  --out NEW_OUTPUT_DIRECTORY
\end{verbatim}
此处反斜杠仅表示排版换行；PowerShell 中请将命令写为同一行。重放不调用模型，只复核已有路径和几何结果，不能当作新模型实验。输出目录必须不存在。
\section{验证口径与异常处理}
原始路径验收 FAIL 与最终恢复 PASS 同时保留；SAFE\_STOP 不计作 REACHED。没有合格恢复路径时保持原始目标与机器人尺寸，不通过缩小机器人、删除障碍或移动目标来制造成功。

认证失败、额度耗尽、接口超时、模型断线等属于基础设施问题，与导航策略缺陷分开。未知用量保留 null。所有公开材料不得包含 Key、个人配置、未经审查的原始会话或本机隐私路径。
