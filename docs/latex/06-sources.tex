\section{软件来源}
AGH 来自 AgnesAI-Labs 官方仓库，固定提交见技术指南；上游源码独立获取，不把上游代码冒充本团队原创。React、Vite、TypeScript、FastAPI 等依赖通过包管理器安装，具体版本与许可证以各依赖元数据为准。公开仓库不搬运 node\_modules、Python 虚拟环境或官方运行时源码。

WorldGuard 业务实现包括导航测试工作流、受限工具适配、独立几何验收、结果与证据组织及工作台集成。使用 Codex 辅助开发与材料制作，团队职责见成员声明。
