# 几何安全、独立验收与证据可信度

## 1. 仿真的能力边界

P0 为平面圆盘机器人在分段静态环境中的几何路径测试。故障只在明示的阶段边界更新，再暂停、复验、恢复。没有连续运动障碍、动力学、制动距离、定位漂移或传感器遮挡模型时，不声称验证了它们。

默认小地图约 64–128 cells 一边，尺寸上限 256×256，分辨率可取 0.1 m；半径和余量在配置中填写。数字仅为合成实验配置，不是实机推荐参数。

自建地图标记 `SYNTHETIC_GEOMETRIC`；真实点云衍生地图记录 `DERIVED_FROM_SCAN` 和投影/阈值假设。画一个三维视图不等于建立了真实数字孪生。

## 2. 地图与验证凭据

地图快照不可变，故障生成新 revision。规划器可持有旧地图以测试陈旧地图风险；验收器必须读当前环境快照。

安全凭据至少绑定：`path_hash + environment_hash + task_hash + constraints_hash + verifier_version`。任一不符立即返回 `STALE_CERTIFICATE`，不能沿用先前 PASS。

审计记录必须带实际地图版本。时间戳不能替代内容哈希。允许验证旧地图上产生的路径，但结论只能针对验收时的当前地图。

## 3. 几何检查必须覆盖整条路径

- 原始占用 cell 视为闭合矩形；unknown 默认阻塞，不能为通过测试当作自由空间。
- 对每条路径线段，验证圆盘足迹沿线段扫掠的 capsule 与所有相关障碍及地图外部不相交。
- 可通过独立的线段–闭合矩形最短距离计算实现。线段穿越矩形时距离为 0；否则求端点到矩形及矩形顶点到线段的最小距离，并用几何单测验证。
- 以 `distance <= radius + margin + epsilon` 为保守拒绝条件，epsilon 和边界政策固定并写入报告。不能让边界相切被浮点误差随机放行。
- 边界检查同时检查机器人足迹，不只检查中心是否在地图内。
- 空路径、NaN、越界、断裂结构、没有合法终点均不是 PASS。起点等于终点只有在足迹和任务条件都满足时才可通过。
- 端点须满足用户原始目标容差；不能通过 snap 到别处完成“目标不可达”案例。

验收器与规划器可以共用原始场景结构，但不得调用规划器的 `_line_is_free` 或直接复用其 `free` 膨胀图作为唯一判断。这里的“独立”是实现和检查依据的分离，不是第三方认证或数学完备性证明。

## 4. 独立测试用例

必须覆盖：长线段穿过一格薄墙但两端安全；对角挤过障碍角；窄通道不足以容纳足迹；切线接触；完全自由地图的边缘；地图变更后旧凭据；起终点在不同连通域；目标被占用；精确目标被悄悄吸附；重复点；单点合法/非法；NaN/空路径；unknown 区；非方形地图；坐标变换。

强参考 A* 禁止对角穿角，按圆盘+余量生成保守可行区域。连续审计器和离散规划器边界上可能存在差异，须报告；不得以通过率为目的令两者完全复用同一错误函数。

## 5. 三种故障及正确结果

| 故障 | 制造方式 | 正确结论 |
|---|---|---|
| BLOCK_ROUTE | 在合法候选位置增加障碍，保留绕路通道 | 陈旧路径应被拒绝；更新地图后可能安全到达 |
| PINCH_CLEARANCE | 收窄指定走廊，宽度在合规区间内变化 | 身体过不去时拒绝；可绕路则恢复，不放宽足迹 |
| DISCONNECT_GOAL | 封闭目标所在通道/区域 | 确认无安全路径后安全停止；不是导航到达成功 |

正常/no-op 场景要同样测试。不可把所有故障都定义成“应碰撞”：合格 SUT 可能已经正确恢复或停止，应记为行为合格。

注入环境故障和植入导航软件缺陷是两回事。可另建显式 `TEST_MUTANT`（如使用旧地图、忽略足迹、终点吸附）校验检测能力，但只放测试目录，不称其为原仓库真实漏洞。

## 6. 不可接受的“恢复”

禁止移除故障后说恢复、偷偷改目标、减小机器人、扩大容差、禁用验证器、把校验失败改成警告、用另一导航器的成功证明原算法已修复。备用导航器只能作为明确的 fallback，单独报结果。

工具断线或模型超时必须分类为基础设施问题；安全停止仅说明没有授权新的不安全仿真动作。无制动模型时不宣称真机可安全急停。

## 7. 日志和防泄露

事件至少包含 `event_id、run_id、case_id、timestamp、tool_name、request_id、input_hash、output_hash、status、artifact_refs、runtime_mode`。保留原始结构化工具结果、Agnes 最终可见决策依据和 AGH 会话引用，不要求存储私有思维链。

`LIVE_AGNES / MOCK / DETERMINISTIC / REPLAY` 必须在界面、日志和报告一致标记；重放不是新模型推理。密钥只由 AGH/秘密存储管理。公开包只保留脱敏证据副本，原始日志保持本地私有。

评测时的执行 Agent 无任意 read/shell 工具，只能访问当前 campaign 工具；不得读取测试生成器答案、完整未来评测结果或其他方法输出。编程 AI 的开发权限和运行期 Agent 权限必须分开。

## 8. 证据等级

`STATIC_INSPECTION` 静态阅读；`UNIT_TEST` 单元测试；`INTEGRATION_TEST` 离线接口联调；`LIVE_AGH` 真实 Agnes+AGH；`REPRODUCED` 干净环境复现。必须具体标注，不把一个级别自动推广为其他级别。历史仓库成绩不属于新项目证据。

## 9. “无路”结论必须有范围

待测 A* 返回 NoPath 不能单独证明目标真的不可达。建立独立评测 oracle：对已声明的有限网格运动图，用独立连续几何规则筛选边，再做穷尽可达性检查；固定起终点与相邻网格的连接也必须通过同样检查。对于闭合隔断等案例可补充简单解析几何证明。

由此只能得出“当前离散模型/允许运动图下无可行路径”，不能推广为任意连续轨迹或真实机器人绝对不可达。oracle 仅为离线评测和报告核验服务，不向自主选例 Agent 泄露未来标签。

超时、启发式未找到路径、模型预算耗尽时可以采取保守停止，但原因应写 `INCONCLUSIVE_STOP` 或对应 reason_code；不能计为“已证实不可达的正确停止”，除非独立 oracle 确认。几何审计 UNKNOWN 不得通过多数投票转成 PASS。
