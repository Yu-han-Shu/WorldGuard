# WorldGuard｜所有执行 AI 必须遵守的工程边界

## 工作目标

实现一个可操作的机器人导航测试工具：**选故障案例 → 执行待测导航器 → 独立检查 → 依据反馈复测/恢复 → 导出证据**。科研指标支持产品价值，不能替代产品；页面不能替代真实工具执行。

## 操作规则

- 每次只执行被指名的批次，先读项目状态及指定规范。应写代码和运行测试，不要只提交设计方案。
- 批次中的文件路径均为目标规范，尚未创建前不能假装已存在。测试名和 CLI 是需要实现的契约，不是声称本包已实现的工具。
- 原仓库、用户其他目录、生产服务和全局配置只读。新项目有未提交改动时先列出并保留；不 `reset --hard`、不强制推送、不删除历史。
- 不自动创建公开仓库、提交赛事表单、签署声明、发布社媒、发邮件、购买服务或启动真实设备。必要时写入人工操作清单。
- 用户授权的工作目录内可创建代码与隔离虚拟环境；系统级安装、全局权限变更和付费网络调用需要现有明确授权。不得读取或打印密钥值，不能把凭据写入提示词、日志、截图或包。
- 无授权模型预算时 `external_model_calls_allowed=false`。可完成离线工作，但不能把 MOCK 标成 LIVE。授权后严格执行运行预算，超限停止，不自动升级套餐。
- 2026-10-15 用户提供的新公告明确：必须使用 AGH，允许合法第三方模型。实际使用的全部模型需登记；不能悄悄更换模型、伪装提供方或把调试调用混入选定证据。传统确定性算法不是模型 API。详见 SUBMISSION_RULES_CURRENT.md。
- 开发 AI、第三方素材和成员实际贡献如实披露。新版公告取消模型仅限 Agnes 的旧口径，但不免除独立完成、来源及使用权说明。

## 代码与真实执行

Python 核心默认 3.11，采用实际环境可安装版本并锁定依赖；AGH 按核实过的官方 checkout。中文文档 UTF-8。Windows 不混用 POSIX shell、PowerShell、cmd 的语法。首批应登记 OS/shell，并提供对应启动方式。

用类型和数据校验守住接口，用有限超时和重试守住资源。MCP stdio 的 stdout 只能传协议，日志写 stderr。禁止 `eval`、任意上传脚本执行、宽泛 shell 工具和无白名单外部 URL。

实际运行输出才可写 PASS。未运行写 NOT_RUN，外部依赖不足写 BLOCKED，部分完成写 PARTIAL。不得为了通过验收删测试、改安全阈值、填示例结果或把已有历史成绩写成新实验。

## 不能突破的安全定义

1. 大模型负责测试选择与恢复编排，不签发安全结论。
2. 验收器必须检查完整线段的机器人足迹，不仅检查路径点。
3. 校验依据为当前原始地图、原始约束和固定目标；不得只复用规划器生成的膨胀图。
4. 地图/约束/路径一变，原验证凭据失效；目标不可达不能静默改成另一个目标。
5. SAFE_STOP 不是 REACHED；未撞到东西也不等于完成了任务。
6. API 超时、模型断线、资料不足不得被说成目标导航算法的缺陷。
7. 仿真结果不等于实机安全、物理安全认证或通用世界模型。

## 范围与取舍

只做单机器人、二维静态几何加分阶段故障更新、三类故障、小地图、一个工作台。Open3D、3D 展示、ROS 适配为非必要增强，不拖累核心。不要搬迁 caigen 整套后端或数学 Agent 模型链。

发现真正价值可能不成立时保留负结果，不再换名字扩大题目。固定脚本和强规则基线应共享同等资源；不能靠故意削弱基线让 Agent 获胜。
