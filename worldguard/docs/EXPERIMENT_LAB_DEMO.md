# WorldGuard 实验舱：90 秒演示

主线：**发现失败 → 对照干预 → 独立验收 → 绑定证据**。

## 反事实实验舱

完成一次复杂仓库堵路评测后，点击“进入反事实实验舱”，选择有原始失败的案例，运行实验。

- A 保留原始路径，在真实地图上重新验收。
- B 用同一导航器、同一策略，只更新规划器看到的地图，再规划与验收。
- C 在 B 的地图上使用净空权重 3.0 的策略候选，再规划与验收。JSON 策略保留其转弯代价；参考 A* 改用带权 A* 时，明确标记导航器实现也发生了变化。

三条分支的真实地图、起终点、机器人尺寸、安全余量、验收器相同。点击 B / C 切换与 A 的双地图对照，按路径比例同步回放；这不是动力学时间仿真。

可讲：“我们让同一个失败现场产生几个可比较的实验分支，观察哪种干预有效。验收器决定结果，原始失败保留。”

新增两次规划单独计数，每次最多 10 秒，不消耗模型请求；这是固定模板的受控实验，不声称模型自主设计了这些分支。结果持久化，重复点击直接返回原记录，包含在完整证据包中。对话 Agent 可以读取已保存实验并解读；未发起对话时不新增模型调用。

## 执行证据护照

切到“证据护照”，默认打开已通过的恢复路径。展示地图、任务、机器人约束、路径、验收器版本的绑定；打开时执行绑定检查和独立几何复核。

点击“在路径上加障碍”：仅在副本的路径中点增加障碍，旧凭据失效，副本重新验收会显示碰撞。点击“增大机器人半径”：旧凭据同样失效，但新条件下的路径是否仍安全由重新验收决定。两种结果不可混同。

可讲：“通过不是永久标签。输入条件一变，旧凭据不能继续通行；每一次接受，都必须对应当前条件。”

原始失败路径不生成通过凭据。下载的护照包含完整快照、路径、审计和内容指纹。哈希提供内容一致性检查，不是防伪签名、第三方认证或真实机器人安全保证。

## 讲述边界

不把更新地图叫成修复代码，不把单图改善叫成跨场景泛化；超时和无路径分支显示未定，不计为安全到达。实验是二维静态几何范围，未实现学习式世界模型、连续动态障碍或自动代码修复。
