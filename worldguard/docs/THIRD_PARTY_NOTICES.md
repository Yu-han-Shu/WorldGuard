# 第三方来源

本项目源码未复制旧导航仓库、AGH 源码或私有资产；参考导航器和验收器为本轮新实现。
AGH 使用工作区独立官方 checkout，版本及路径配置不随包分发。
MCP SDK https://github.com/modelcontextprotocol/python-sdk ：MIT，安装包的 LICENSE 随其分发。
Streamlit https://github.com/streamlit/streamlit ：Apache-2.0，安装包的许可文件随其分发。
Python 及全部锁定依赖通过各自官方包安装，具体版本见 requirements.lock；未将第三方二进制打入候选包。
本项目自身最终开源许可由权利人决定；本轮仅本地私有开发，未自动授予公开发布许可。
